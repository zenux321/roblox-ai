# Vault demonstrativ Roblox AI Builder

Deschide acest folder ca vault separat în Obsidian sau copiază `RobloxAIBuilder/` în vaultul ales. Nu este nevoie de plugin. Nu crea un vault în interiorul altui vault.

Aplicația viitoare scrie numai în subfolderul dedicat și păstrează datele runtime/secretele în afara lui. Fișierele de aici sunt șabloane fără date personale.
