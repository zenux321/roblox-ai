# Local implicit, API opțional

Decizie: modele locale, Markdown și SQLite; API plătit dezactivat implicit.

Motiv: cost minim și date personale păstrate local. Consecințe: performanță dependentă de hardware și calitate variabilă a modelelor; integrarea API rămâne opțională și bugetată.
